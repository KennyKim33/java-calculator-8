# 문자열 덧셈 계산기

## 기능 요구 사항
### 분리
- [x] 기본 구분자와 커스텀 구분자를 기준으로 문자열을 분리할 수 있다.

### 커스텀 구분자
- [x] 앞의 기본 구분자(쉼표, 콜론) 외에 커스텀 구분자를 지정할 수 있다.
- [x] 커스텀 구분자는 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용한다. 
- [x] 커스텀 구분자을 입력 받을 시, 기본 구분자와 함께 사용할 수 있다.

### 덧셈
- [ ] 숫자의 합을 반환한다.

### 예외 `IllegalArgumentException`
- [x] 커스텀 구분자의 형식을 지켜야한다. `(\\ /n)`
- [x] 커스텀 구분자는 하나만 받을 수 있다.
  
## 입출력 요구 사항
### 입력
- [x] 구분자와 양수로 구성된 문자열을 입력받는다.


### 출력
- [x] 덧셈 결과을 출력한다.
